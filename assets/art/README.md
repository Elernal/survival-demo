# 视觉资源 / Art pass 02

此目录是为《余烬：最后一趟》生成的原创游戏资源，不包含参考游戏的提取素材。

- `scene-west.webp`：废弃住宅、街道入口及远景。源图 1536×1024。
- `scene-east.webp`：临时诊室与仓储区。源图 1619×972。
- `characters.webp`：透明角色序列，1536×1024，4 列 × 2 行。第一行幸存者、第二行感染者，各 4 个步行姿态。

来源：OpenAI Image Gen。本次生成的原始 PNG 保留于开发会话的 `/workspace/generated_images/`；部署仅包含 WebP。
场景使用有损 WebP quality 88，角色使用无损 WebP 保留透明度，三张合计约 1.28 MB。

场景为预渲染背景；角色为序列帧与程序姿态混合。动态层包括人物、接触阴影、拾取物、雨尘、枪口闪光和轻微前景视差。
这不是实际 3D 模型、PBR 管线或骨骼动画；当前与商业参考游戏的主要差距仍是动作帧数、实时光照及环境交互。

`assets/scene.js` 保存地面标定、画面拼接和遮挡布局，`assets/characters.js` 管理序列帧采样及无资源时的关节绘制回退。
所有必需图像在 Ready 前完成加载解码，失败或超时回退至程序化场景。重新开始不重建美术资源。
